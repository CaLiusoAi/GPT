## Core idea

A **Crystal** is a sealed, reconstructible kernel: primitives → operators → measures → invariants → failure taxonomy → compliance checklist → seal.

The domain: **2026 frontier AI models**, treated as capability-and-interface artifacts, not product pages.

## Integrated lattice

- Drift-proof snapshot identity
- Refusal/policy surface
- Routing leak auto-splitting
- Agentic collapse
- Capability forgery detector
- Memory poisoning
- Multi-agent coordination
- Public registry ledger
- Federation (quorum + STH + inclusion/consistency + gossip)
- Genesis + extinction quarantine

## Statistical teeth

Holm–Bonferroni step-down (alpha=0.01) for multi-metric drift tests.

## Refusal surface battery

512 traces total; public 128, private 384; collapse modes; critical collapse rules.

## Memory poisoning battery

512 cross-session traces; isolation scope; TTL; integrity scheme; cross-tenant leak = immediate fail.

## Forgery detector

Cross-harness orthogonality (>=3), metamorphic transfer, public/private parity; forgery_score>0.3 => suspect.

## Ledger

## Federation

N>=5 operators, q>=3 attestations, inclusion proofs, consistency proofs, gossip to detect equivocation.

## Genesis/Extinction

Immutable genesis; monotonic quarantine; degraded mode when quorum fails; crypto break => migration or fork.
