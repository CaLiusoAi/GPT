
# Crystals

This repo implements the following crystals and their digests:

1. Refusal/policy surface (`crystal_lattice/refusal_surface.py`)
2. Routing leak detection (`crystal_lattice/routing_leak.py`)
3. Agentic collapse surface (`crystal_lattice/agentic_collapse.py`)
4. Memory poisoning surface (`crystal_lattice/memory_poisoning.py`)
5. Multi-agent coordination surface (`crystal_lattice/multi_agent.py`)
6. Capability forgery detector (`crystal_lattice/forgery.py`)

Drift testing + Holm correction are implemented in `crystal_lattice/drift.py` and `crystal_lattice/holm.py`.
